# 完整课件的平台交付验收

本页对应[英文源规格](/spec/06-delivery/courseware-platform-sync)。

课程工作区和结构化课堂编辑器分别提供**同步到平台**和**发布**操作。两者都不要求重新提供原始 PPT 或教案。旧客户端仍可使用原始 PPT 导入 API。

验收顺序：

1. 完成原生课件和讲解配音。首次同步前点击发布：提示先同步，不提交发布请求。
2. 点击同步到平台，导出完整的 PPTist 场景、动作、音频和媒体。确认讲解中针对 PPT 组合对象的聚光灯在平台播放和本地播放时覆盖同一组合。平台只创建一份课程草稿。没有编辑时重复同步，保持原有绑定和修订版本。
3. 发布：等待签名课件包准备完成，再上架课程。播放使用已归档的讲解音频，不重新生成 TTS。原生客观题先展示原始页面，再进入标准评分 Quiz；已保存的原生 Quiz 保留题目配置、反馈模式、答案以及题目和选项图片。讨论和简答教学检查点仍由教师引导，除非已保存的教案明确将该页标记为 Quiz。
4. 在本地修改文字、页面、音频或教学步骤。点击发布时提示先同步。再次同步：沿用同一课程和课堂，创建新草稿修订，原有线上 URL 和版本保持不变。只有明确点击发布才切换线上课件包，且仅切换一次。
5. 在管理端修改云端草稿后，再从本地同步。显示冲突，并提供明确的替换云端草稿操作。取消时保留云端内容；确认时只替换界面显示的修订，后续云端编辑会再次触发冲突。发布前线上内容保持不变。
6. 提交后中断，或响应丢失后重启客户端。重复操作应恢复原始回执，不创建重复课程或额外发布版本。如果本地已有新编辑，恢复较早的发布不能顺带同步这些编辑。
7. 导出期间切换账号、工作区、会话或原生源文件：拒绝采用过期结果。资源缺失或损坏、教学内容不符合 MAIC、讲解配音未完成的课件包均不能同步或发布。只有已保存的讲解策略明确将相应页面 ID 标记为静音时，才允许静音页。原生同步指纹包含已保存的 PPTX 字节和经过验证的转换器清单，因此更换转换 Worker 后必须重新同步才能发布。
8. 转换出现警告时，展示实际诊断并要求明确批准。编辑源文件后批准失效。阻断性转换错误始终禁止发布。
9. 确认旧版 PPT 导入和课程发布仍保持原有行为。

实现依据和部署前提：[交付 ADR](/adr/courseware-platform-delivery)。
