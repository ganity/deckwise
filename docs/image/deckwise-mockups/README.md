# DeckWise 最终产品页面效果图

这组图是基于当前 PI-Desktop 壳层制作的产品目标设计稿，尺寸为 1440×900。左侧任务栏、暗色基调、字体和控件比例沿用现有应用；新增页面覆盖 DeckWise 的完整主流程。

| 文件 | 功能 |
|---|---|
| `01-home.png` | 新建课件、输入主题、添加材料 |
| `02-generating.png` | Pi Agent 执行分析与 PPT Master 生成过程 |
| `03-svg-preview.png` | 生成期间的 SVG 页面预览与视觉检查 |
| `04-completed.png` | PPTX 生成完成、打开编辑器或导入 MAIC |
| `05-editor.png` | 应用内嵌 Web Office 编辑 PPTX |
| `06-revisions.png` | 版本与活动记录 |
| `07-import.png` | 导入 MAIC 课堂空间 |
| `08-settings-model.png` | 模型、服务和默认生成参数 |
| `09-login.png` | 登录页 |
| `10-skills.png` | PPT Master Runtime、模板与 SVG 服务 |
| `11-toast.png` | 导入完成通知 |
| `12-error-retry.png` | 生成失败、保留中间结果与重试 |

`deckwise-final-product-overview.png` 是全部页面的总览图。页面目前是产品视觉规格，不代表对应功能已经完成实现。
