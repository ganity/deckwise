# 独立题目页与正文讲解分离回归

本次修复在 `courseware-par-A` 完成，接续同目录上一轮原生占位页与 MAIC 格式工作。

## 已确认的原因

截图对应的 Freeze 活动在原始规划中含有人物、地垫、文字和游戏讲解，却同时被标为带问题的 interactive 页。编译器因此将其当作独立检查点，换成问答模板；讲解生成和完成度检查又会给检查点补充完整讲解。普通正文的讲解模型还可以输出额外提问，形成另一种混放。

## 修复后的行为

- 活动配图、规则和讲解留在正文页。需要学生作答时，在规划阶段另建独立 Quiz 或交互检查点页，不占正文页数。
- 独立题目页使用清晰的 Quiz/课堂互动模板；题干、选项、图片、正确答案、参考答案和约束提示通过专门编辑器修改。
- 规划、Host 审批和编译均拒绝把正文素材塞进独立题目页，不再静默丢弃正文内容。
- 新生成的独立题目页没有原生讲解步骤。题目由标准 MAIC Quiz 内容或 checkpoint action 保存，完成度检查不会要求补讲解。
- 正文讲解生成遇到额外提问会纠正输出；Host 保存入口也拒绝把提问写到正文，或把完整讲解写到独立题目页。
- MAIC 的 Quiz 仍是 `type: "quiz"`；交互仍是 `type: "slide"` 加 `interaction_checkpoint`。本地 Quiz 导航占位画布不进入最终 MAIC 内容。
